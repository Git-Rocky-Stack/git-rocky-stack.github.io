# git-rocky-stack.github.io

The root of the host that serves this account's GitHub Pages sites. It holds only `robots.txt`: crawlers read robots.txt at the root of a host and nowhere else, so this is where each site's sitemap is listed.

| Site | Sitemap |
|---|---|
| [STX Downloader](https://git-rocky-stack.github.io/STX-Downloader/) | [sitemap.xml](https://git-rocky-stack.github.io/STX-Downloader/sitemap.xml) |
| [sysmonitor-windows](https://git-rocky-stack.github.io/sysmonitor-windows/) | [sitemap.xml](https://git-rocky-stack.github.io/sysmonitor-windows/sitemap.xml) |
| [Bentlines](https://git-rocky-stack.github.io/Bentlines/) | none yet |

A site that gains a sitemap gets a `Sitemap:` line in `robots.txt`. `.nojekyll` makes Pages publish these files as they are, and there is no page at the root.
